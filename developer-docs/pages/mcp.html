MCP 集成

MCP 让 Atelier 可以加载外部工具服务器，把文件系统、浏览器、数据库或其他服务暴露成模型可调用的工具。它属于工具层的扩展入口。

1. 配置方式

MCP server 通常配置在 config.yaml。每个 server 指定启动命令、参数和环境变量。Factory 创建 ToolRegistry 时读取配置并把 MCP 工具注册进统一工具列表。

2. 和内置工具的关系

模型看到的是统一 ToolSpec。内置工具和 MCP 工具在 LLM 侧没有本质区别，执行时都经过 ToolExecutor、审批、hook 和结果回填。

3. 加载生命周期

  1. 读取配置中的 MCP server 列表。
  2. 启动或连接 server。
  3. 读取 server 暴露的 tool schema。
  4. 包装成 Atelier 的 ToolSpec。
  5. 执行时把参数转发给 MCP server，再把结果转成 ToolResult。

4. 安全注意

MCP 工具可能访问本地文件、网络或第三方服务。不要因为它来自外部协议就绕过安全层。建议高风险 MCP 工具默认放进 confirm_tools，并记录 hook 事件。

5. 调试方法

  • 先确认 MCP server 能独立启动。
  • 查看 ToolRegistry 中是否出现对应工具名。
  • 检查 LLM tool list 中是否包含 MCP schema。
  • 如果模型没有调用，通常是描述不清或 persona allowed_tools 没放行。
