运行方式与目录结构

这一页说明如何把项目跑起来、如何测试、每个目录负责什么。它适合新成员接手项目时先读。

Python 环境

项目要求 Python 3.11+。当前机器上可用解释器位于：

D:\Anaconda\python.exe

安装依赖和开发依赖：

D:\Anaconda\python.exe -m pip install -e .[dev]

启动 Web 服务

Web 后端使用 FastAPI + Uvicorn。启动命令：

D:\Anaconda\python.exe -m uvicorn api.rest:app --host 127.0.0.1 --port 8000 --reload

启动后访问：

http://127.0.0.1:8000

前端由 api/rest.py 直接返回 static/index.html。静态资源挂载在 /static。

启动 CLI

CLI 与 Web 复用同一套 build_engine()、provider、ToolRegistry 和 AgentEngine。

D:\Anaconda\python.exe cli.py

可用参数包括 provider、persona、question mode 等。CLI 内部也支持命令系统，例如列工具、列 persona、查看状态。

运行测试

D:\Anaconda\python.exe -m pytest

常用针对性测试：

D:\Anaconda\python.exe -m pytest tests/test_engine.py tests/test_tools.py
D:\Anaconda\python.exe -m pytest tests/test_spawn_agent.py
D:\Anaconda\python.exe -m pytest tests/test_storage.py tests/test_tasks.py

目录结构

目录说明
api/REST 和 WebSocket 入口。
harness/engine/AgentEngine、ReactLoop、状态机、压缩、PromptCache。
harness/tools/工具 schema、注册、执行和内置工具。
harness/storage/Session、Checkpoint、Memory、Plan 的抽象与后端。
harness/llm/OpenAI-compatible 和 Anthropic provider。
harness/mcp/MCP client、transport、bridge。
.myharness/personas/persona 和 AgentProfile 配置。
.myharness/skills/项目级 skill。
static/当前 Web 应用前端。
developer-docs/本开发者文档站。

开发注意事项

  • 改工具时要同时检查 harness/factory.py 的 ALL_TOOLS 和 config.yaml 的 tools.enabled。
  • 改会话状态时要确认 /sessions/{id}/state 返回值和前端渲染同步。
  • 改多 Agent 时要检查 session metadata 中的 parent_session_id、spawn_depth 和 display_name。
  • 改持久化结构时要补 SQLite 与内存后端两套实现。
