# 验收标准 — 老年 AI 陪伴设备

> 本文件与 `design_system.json` 和 `deliverable_manifest.json` 一一对应。Critic 将逐条评分。

---

## 1. 设计系统一致性 (System Consistency)

- [ ] **色彩一致性**：所有 PNG 渲染中产品表面色值必须引用 `design_system.palette.tokens` 中的 hex 值（surface-cream `#F5F0E8`、surface-warm-gray `#D4CFC7`、accent-wood `#C4A882`、glow-amber `#E8B87A`）。不得出现纯白 `#FFFFFF` 或纯黑 `#000000`。
- [ ] **形态一致性**：所有产品视图（01-form-study 至 10-exploded-view）中的设备形态必须保持同一设计——圆润有机、无棱角、最小圆角半径 ≥8mm。
- [ ] **材质一致性**：织物包裹主体 + 浅木底座 + 哑光软触塑料的组合在所有视图中保持一致。CMF 方案板 (05-material-board) 的材质样本必须与产品渲染中使用的材质视觉匹配。
- [ ] **母题一致性**：breathing-arc 母题系统（breath-ring / pebble-curve / warm-glow）在展示板和氛围渲染中可辨识。不得出现几何图案（六边形、网格、电路纹）。
- [ ] **字体一致性**：所有标注文字使用 humanist sans-serif（思源黑体/Source Sans Pro），body 字号 ≥16pt，mono 用于技术参数。

## 2. 需求覆盖 (Requirement Coverage)

- [ ] **温暖感**：产品在 2 秒内传达"温暖 + 陪伴"感受——surface-cream 主色 + glow-amber 呼吸灯 + 织物纹理共同作用，无冷色调主导。
- [ ] **安全感**：形态圆润无锐角，底座稳定（宽高比 1.3-1.5:1，底座略窄），视觉重心低，暗示不易倾倒。
- [ ] **适老化**：04-ergonomic-diagram 清晰展示按钮直径 ≥25mm、设备高度适合坐姿桌面使用、触控区域可达。
- [ ] **家居融合**：09-lifestyle-context 中设备像家居装饰品而非电子设备，与木质家具、织物、植物和谐共存。
- [ ] **非医疗感**：所有视图中不得出现医疗器械、临床白色、监控摄像头、数据仪表盘等元素。
- [ ] **非幼稚化**：不得使用高饱和原色、卡通表情、玩具质感。产品应被感知为"有品质的家居物件"。
- [ ] **情感化光交互**：glow-amber LED 呼吸灯在产品中可见（02-form-variant、07-detail-connection），传达"有生命感的存在"而非"机器运行指示灯"。

## 3. 参考依据 (Reference Grounding)

- [ ] **竞品差异化**：产品形态不得直接复制 ElliQ（头部+光环）、PARO（仿动物毛皮）、Buddy（蛋形+屏幕脸）、MiRo（仿生动物）。brand_lock.md 中的 do_not_duplicate 清单全部遵守。
- [ ] **研究引用**：形态策略引用 PMC 2016 研究（圆润边缘、非威胁性家居感）；CMF 策略引用 Kvadrat×B&O 合作（声学透明织物、暖中性色）；交互策略引用 Frontiers 2024 论文（语音优先、主动互动、允许沉默）。
- [ ] **参考图使用**：13 张研究参考图作为风格和语境参考，不直接合成到交付物中。

## 4. 视觉品质 (Visual Quality)

- [ ] **渲染品质**：所有产品渲染达到工业设计展示级——正确的材质反射、柔和的 2700K 暖光照明、无 AI 生成瑕疵（多余肢体、变形文字、不合理阴影）。
- [ ] **构图品质**：每张 PNG 构图有明确主体、合理留白、视觉层次清晰。产品不居中呆板，利用三分法或黄金分割。
- [ ] **色彩品质**：整体色调温暖统一，无突兀的冷色或高饱和色块。shadow-warm `#8A8279` 用于所有阴影区域，不使用纯灰。
- [ ] **细节品质**：07-detail-connection 微距视图展示真实材质纹理——织物编织可见、木纹自然、塑料哑光柔和。

## 5. 交付完整性 (Deliverability)

- [ ] **数量完整**：4 张设计规范板 + 10 张产品效果图 + 1 个 HTML 画廊 = 15 件交付物（min_items = 18 含 3 张额外规范板）。
- [ ] **路径正确**：所有文件路径与 `deliverable_manifest.json` 一致——规范板在 `artifacts/design-spec/`，效果图在 `artifacts/generated-images/`，画廊为 `artifacts/00-gallery.html`。
- [ ] **格式正确**：所有效果图为 PNG 格式，1536×1024 像素。画廊为单个 HTML 文件，无外部依赖。不得产出 SVG。
- [ ] **画廊结构**：00-gallery.html 包含 Design System 概览（色板色块）、Design Specifications 区域（4 张规范板）、Generated Artifacts 区域（10 张效果图），响应式布局。

## 6. 人机工程验证 (Ergonomic Validity)

- [ ] **按钮尺度**：04-ergonomic-diagram 中标注的按钮直径 ≥25mm（老人指腹平均 20-25mm）。
- [ ] **设备尺度**：08-scale-reference 清晰传达 120-150mm 直径的掌中尺度，重量暗示 <1kg。
- [ ] **使用姿态**：设备适合坐姿桌面使用（床头柜/边桌/书架），不需要弯腰或抬手。

## 7. 情感共鸣 (Emotional Resonance)

- [ ] **陪伴感**：整体设计传达"有一个温暖的存在陪在身边"——glow-amber 呼吸灯如壁炉光芒（引用 Anthro-Age 2022 研究），织物材质如靠垫般可亲。
- [ ] **尊重感**：产品不像"给老人的特殊设备"，而像"任何人都想拥有的美好物件"——去医疗化、去标签化。
- [ ] **自然感**：形态取法自然（鹅卵石），材质取法自然（木、织物），光效取法自然（呼吸节奏、壁炉暖光），整体"自然如呼吸"。
