# Acceptance Criteria — 上海创智学院产品周边系统

- [ ] **System consistency:** 所有 PNG 与 00-gallery.html 必须统一引用 `plan/design_system.json`，且可明确识别 `sii-blue`、`deep-space`、`paper-white` 为主系统颜色；任何使用 `signal-cyan` 或 `steel-mist` 的场景均为辅助，不得漂移出系统色域。
- [ ] **Mind identity match:** 所有主视觉在 2 秒内读作“科技未来 + 可信 + 克制 + 系统化”；证据必须来自 `future-grid ribbons`、`sii-blue` / `deep-space` / `paper-white` 的组合，以及避免炫技赛博朋克效果。
- [ ] **Official identity preservation:** 每个涉及品牌识别的成品必须使用正式名称 `上海创智学院` 与/或 `Shanghai Innovation Institute`；不得出现新校徽、新缩写主标或任何伪造 logo。
- [ ] **Research limitation acknowledged:** 至少 3 张成品采用“官方公开场景 + 系统图形覆盖”的方式证明延展逻辑，而不是假设存在可编辑 logo 文件；不得伪装为已获得独立 protected/logo 资产。
- [ ] **Typography discipline:** 所有成品必须只使用 `display`、`headline`、`subhead`、`body`、`caption`、`mono` 这些既定角色表达层级；不得出现无法归类的装饰性字体风格。
- [ ] **Motif continuity:** 所有需要辅助图形语言的成品必须出现 `future-grid ribbons` 组件中的至少一种：`rectilinear frames`、`data lines`、`modular ribbons`、`micro-label strips`、`cropped image windows`。
- [ ] **Merch relevance:** 交付集合应清晰服务“产品周边系统”目标；至少 4 张 PNG 必须直接展示通用混合套装或其应用，包括 tote、笔记本、马克杯、贴纸、证件套等合理类别中的若干项。
- [ ] **Reference grounding:** 所有 `image_edit` 项必须使用 manifest 中的官方学院资产 id（`ecosystem-photo-01`、`event-lecture-01`、`homepage-hero-01` 等）作为参考；不得使用 `peer-air-logo` 或 `peer-air-campus` 进入最终成品。
- [ ] **Non-duplication:** 最终成品不得直接照搬官网栏目头图、新闻图原始构图，不得复刻第三方机构识别，也不得出现 `neural-net node clusters`、`generic hexagon tech wallpaper`、`glowing brain or chip icon`、`赛博朋克霓虹紫粉渐变`。
- [ ] **Deliverability:** 必须交付 10 张 PNG + 1 个 `artifacts/00-gallery.html`，文件路径与 `plan/deliverable_manifest.json` 完全一致，且画幅尺寸仅使用允许列表中的尺寸。
