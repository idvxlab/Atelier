# 朱家角古镇游客中心空间设计 — 验收标准

## 1. 系统一致性 (System Consistency)

- [ ] **色彩一致性**：所有12张PNG的色彩基调严格遵循design_system.palette中的10个token。主色调whitewash(#F2EDE4)、tile-grey(#4A4A48)、timber-warm(#8B6B4A)在所有效果图中可见。禁止出现高饱和度荧光色、冷蓝科技色、纯白#FFFFFF或纯黑#000000大面积使用。
- [ ] **材料一致性**：所有效果图的材料表达必须引用design_system.material_atmosphere中的7种核心材料（胶合木、青砖、小青瓦、石材、超白玻璃、耐候钢/黑钢、清水混凝土）。传统材料与现代材料的对话融合在每张效果图中可见。
- [ ] **空间语汇一致性**：每张效果图必须体现motif_system中的至少一个母题（坡屋顶轮廓、水波纹理、木构格栅、月洞门/圆窗）。禁止直接复制传统建筑构件（如具体斗拱形式）或使用具象龙凤、祥云纹样。
- [ ] **光线一致性**：所有室内效果图遵循design_system.light_strategy — 自然光为主（天窗、玻璃幕墙），暖色调人工照明（warm-amber #D4A853，2700-3000K）为辅。禁止均匀泛光或冷白光。
- [ ] **气质一致性**：所有空间效果图传达「温润雅致、文化沉浸、舒适宜人」的氛围。非冷硬现代也非仿古复古，而是新旧对话的当代转译。

## 2. 需求覆盖 (Requirement Coverage)

- [ ] **功能分区完整**：02-master-plan-zoning清晰标注8个核心功能区（咨询接待、票务服务、信息展示、文化展览、游客休憩、卫生服务、纪念品展示、无障碍服务）。
- [ ] **流线组织清晰**：03-circulation-flow区分4种流线类型（游客散客、团队客、无障碍、后勤），体现入口→咨询→展示→休憩→离园的5段序列。
- [ ] **空间序列完整**：04-spatial-sequence展示5个空间节点的收放节奏（开敞→半围合→沉浸→温馨→开敞）。
- [ ] **关键空间覆盖**：06入口大厅、07咨询接待区、08文化展示区、09休憩区各有独立效果图，体现各自功能特征与氛围差异。
- [ ] **场地关系表达**：01-site-context-relation清晰展示游客中心与古镇历史街区、漕港河水系、传统建筑的空间关系。
- [ ] **立面/外观表达**：10-facade-elevation展示坡屋顶当代转译、木构+玻璃+石材立面组合、与古镇环境的尺度协调。
- [ ] **材质与光线策略**：11-material-light-board集中展示7种核心材料样本与光线策略。
- [ ] **无障碍设计可见**：12-accessibility-scale清晰标注无障碍坡道、低位柜台、通道宽度、扶手座椅、盲文标识等要点。07-reception-area可见低位柜台。09-rest-area可见老年游客友好设计。

## 3. 参考锚定 (Reference Grounding)

- [ ] **先例参考合理**：安仁游客中心（李兴钢）的新旧融合策略、木构表达在05-section-perspective、06-hero-entry-hall、07-reception-area中有所体现，但未复制具体形态。
- [ ] **水乡更新参考**：蟠龙天地的沿河布局与传统现代融合策略在01-site-context-relation、09-rest-area、10-facade-elevation中有所体现。
- [ ] **场地环境参考**：朱家角古镇的粉墙黛瓦、水系、石板街道在01-site-context-relation、10-facade-elevation中可见。
- [ ] **未复制现有游客中心**：未复制无样建筑工作室设计的现有游客服务中心的具体建筑形态。
- [ ] **未复制官方标志**：朱家角古镇旅游区官方标志未被重新生成或修改。

## 4. 视觉品质 (Visual Quality)

- [ ] **人物活动可见**：所有室内效果图（06-09）包含适度人物活动（咨询、休憩、观赏、通行），体现空间真实使用状态。人物着装朴素自然，不喧宾夺主。
- [ ] **光线氛围自然**：效果图光线柔和自然，体现自然光与暖色人工光的层次。禁止过度后期处理或赛博朋克风格。
- [ ] **材料质感真实**：材料表达具有真实质感（木纹、砖缝、石材肌理、玻璃反射），非平面色块。
- [ ] **空间尺度合理**：空间效果图的尺度感合理，层高、通道宽度、家具尺寸符合人体工程学。
- [ ] **分析图清晰**：01-05分析图的信息层级清晰，标注可读，留白率≥30%，无装饰性元素干扰。

## 5. 图面表达 (Typography & Presentation)

- [ ] **字体层级正确**：标题使用display角色（思源宋体SemiBold），说明使用caption角色（思源黑体Regular），标注使用annotation角色（思源黑体Light），导视使用wayfinding角色（思源黑体Medium）。
- [ ] **中英文比例**：图面文字以中文为主，英文为辅。禁止全大写英文无衬线体堆砌。
- [ ] **项目名称规范**：「朱家角古镇游客中心」使用宋体SemiBold，英文副标题使用无衬线Light。
- [ ] **导视标识规范**：导视标识字号≥24pt，对比度≥4.5:1，配合盲文标识。

## 6. 交付完整性 (Deliverability)

- [ ] **PNG数量达标**：产出12张PNG + 1个HTML画廊，共13个交付物，满足min_items=13。
- [ ] **文件路径一致**：所有PNG文件路径与deliverable_manifest.json中的file字段完全一致。
- [ ] **画廊完整**：00-gallery.html嵌入所有12张PNG，按deliverable_category分组，顶部展示palette色板行和type stack，inline CSS无JS无外部资源。
- [ ] **尺寸规范**：分析图/系统板使用1024x1024，效果图/宽幅图使用1792x1024。
- [ ] **无SVG输出**：所有交付物为PNG或HTML，无SVG文件。

## 7. 空间逻辑 (Spatial Logic)

- [ ] **功能布局合理**：平面功能分区符合游客中心运营逻辑 — 咨询接待靠近入口，文化展示位于流线上，休憩区相对安静，卫生间位置便利。
- [ ] **流线无冲突**：游客流线与后勤流线无交叉冲突，团队客流线与散客流线可分可合。
- [ ] **空间序列有节奏**：从入口到离园的空间体验有明确的收放节奏，非单调重复。
- [ ] **剖面关系合理**：坡屋顶形态、天窗位置、木构梁架层次在剖面中表达合理，结构逻辑可信。

## 8. 无障碍与人文关怀 (Accessibility & Human Care)

- [ ] **无障碍坡道可见**：12-accessibility-board清晰展示坡度≤1:12的无障碍坡道。
- [ ] **低位柜台可见**：07-reception-area展示高度≤750mm的低位服务柜台。
- [ ] **通道宽度标注**：12-accessibility-board标注主要通道宽度≥1.8m。
- [ ] **老年游客友好**：09-rest-area展示带扶手座椅，12-accessibility-board包含老年游客人物尺度。
- [ ] **盲文标识提及**：12-accessibility-board提及或展示盲文标识配合。

---

**验收通过条件**：以上所有检查项均通过，或仅有低优先级项（如个别标注细节）存在微小偏差但不影响整体设计意图表达。

**硬失败条件**：
- 色彩体系严重偏离design_system.palette（如出现大面积荧光色或冷蓝科技色）
- 直接复制现有游客中心或官方标志
- 缺少3张以上必需PNG
- 所有效果图均为空无一人（无人文关怀）
- 无障碍设计完全缺失
