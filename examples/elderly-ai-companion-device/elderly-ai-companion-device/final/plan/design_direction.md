# 设计方向说明 — 老年 AI 陪伴设备

---

## 1. 设计愿景

**"温暖陪伴，自然如呼吸"**

设计一款让独居老人感到"有一个温暖的存在陪在身边"的智能陪伴设备。它不是医疗设备，不是智能音箱，不是机器人玩具——它是一件有温度的家居物件，像一块被手掌握暖的鹅卵石，像壁炉里柔和的光芒。

设备的核心情感价值：**陪伴感**（不是监控感）、**安全感**（不是焦虑感）、**尊严感**（不是标签化）。

---

## 2. 形态语言

### 2.1 核心隐喻：鹅卵石

产品形态取法河滩上的鹅卵石——经过水流长年冲刷，没有棱角，握在手中温润贴合。这个隐喻传达：

- **自然**：不是人造的科技感，而是自然界的温暖存在
- **安全**：没有尖锐边缘，不会造成伤害
- **时间感**：像已经陪伴很久的老物件，而非刚买的新 gadget
- **独特性**：每块鹅卵石都不同，暗示每个设备都是独特的陪伴者

### 2.2 形态原则

| 原则 | 说明 | 约束 |
|------|------|------|
| 圆润有机 | 所有边缘 G2 连续，无锐角过渡 | 最小圆角半径 >= 8mm |
| 非人形 | 不使用人脸、眼睛、嘴巴等拟人特征 | 避免恐怖谷效应 |
| 非动物仿生 | 不模仿特定动物形态 | 区别于 PARO / MiRo |
| 稳定感 | 上窄下宽，视觉重心低 | 高宽比 1.3-1.5:1 |
| 小巧亲切 | 掌中尺度，可单手握持 | 直径 120-150mm，重量 < 1kg |
| 无屏幕脸 | 不使用屏幕模拟面部表情 | 区别于 Buddy，用灯光表达情感 |

### 2.3 形态结构

```
        +-------------+
        |  LED 光环    |  <- glow-amber 呼吸灯（情感表达）
        |  (透光织物)  |
        +-------------+
        |             |
        |  织物主体    |  <- surface-cream 织物包裹（温暖触感）
        |  (扬声器)    |     内置扬声器，声学透明
        |             |
        +-------------+
        |  触控按钮    |  <- 大尺寸按钮（>= 25mm），正面易触及
        +-------------+
        |  木质底座    |  <- accent-wood 浅橡木（自然材质）
        +-------------+     充电触点隐藏于底部
```

## 3. CMF 策略

### 3.1 色彩 (Color)

| 角色 | 色值 | 应用 |
|------|------|------|
| 主色 surface-cream | #F5F0E8 | 织物包裹主体表面，占视觉面积 60%+ |
| 次色 surface-warm-gray | #D4CFC7 | 按钮表面、塑料过渡区域 |
| 强调色 accent-wood | #C4A882 | 浅橡木底座，自然材质温暖 |
| 功能色 glow-amber | #E8B87A | LED 呼吸灯，2700K 暖光等效 |
| 辅助色 soft-sage | #A8B5A0 | 健康/平静状态指示（可选） |

**色彩原则**：所有色相饱和度 < 30%，避免任何"科技感"冷色或"玩具感"高饱和色。整体色调如秋日午后的阳光。

### 3.2 材质 (Material)

| 材质 | 应用区域 | 触感描述 |
|------|----------|----------|
| 声学透明织物 | 主体包裹（上 2/3） | 如亚麻靠垫般温暖可亲，可拆卸清洗 |
| 浅橡木（真木或高品质仿木） | 底座环 | 自然纹理，手感温润，暗示品质 |
| 哑光软触塑料 | 按钮、顶部触控区 | 类肤质涂层，防滑，温暖不冰冷 |
| 半透明织物/树脂 | LED 光环导光区 | 光线柔和扩散，无可见灯珠 |

### 3.3 工艺 (Finish)

- 织物：细密编织纹理（非粗麻），手感柔软但不松垮
- 木质：开放漆面，保留木纹触感，非高光漆
- 塑料：细砂纹哑光（120-180 目），不留指纹
- LED 区：内层磨砂处理，外层均匀扩散，光斑不可见

## 4. 交互理念

### 4.1 语音优先，触觉辅助

| 交互方式 | 优先级 | 说明 |
|----------|--------|------|
| 语音对话 | 主交互 | 自然语言交流，无需学习指令 |
| 呼吸灯光 | 情感反馈 | 设备"状态"通过光的节奏传达，无需阅读文字 |
| 大按钮触控 | 辅助交互 | 1-2 个物理按钮（开关/呼叫），盲操作友好 |
| 环境感知 | 被动交互 | 自动检测活动/安静，主动但不打扰 |

### 4.2 灯光作为情感语言

LED 呼吸灯是设备唯一的"表情"：

| 灯光模式 | 含义 | 节奏 |
|----------|------|------|
| 缓慢呼吸（4s 周期） | 待机/陪伴中 | 如熟睡者的呼吸 |
| 柔和亮起 | 正在聆听 | 如有人转头看你 |
| 温暖脉动 | 提醒/通知 | 如轻拍肩膀 |
| 渐暗 | 进入安静模式 | 如日落 |
| 微光常亮 | 夜间模式 | 如小夜灯 |

**关键洞察**（引用 Anthro-Age 2022 研究）：壁炉般的光芒比任何屏幕都更能传达"温暖的存在感"。

### 4.3 主动但不打扰

- 设备可以主动发起对话（"今天天气不错，要不要出去走走？"）
- 但尊重沉默——老人不回应时，设备安静退回陪伴模式
- 健康提醒以关怀口吻而非医嘱口吻（"该喝水了"而非"请补充水分"）

## 5. 情感化设计要点

### 5.1 去医疗化

| 避免 | 替代 |
|------|------|
| 白色/蓝色医疗色 | 暖米色/暖灰色 |
| 屏幕数据展示 | 语音 + 灯光反馈 |
| "健康监测"措辞 | "我注意到您今天..." |
| 临床感材质（不锈钢、玻璃） | 温暖材质（织物、木材） |
| 警报式提醒 | 渐进式关怀（灯光 -> 轻语 -> 重复） |

### 5.2 去标签化

设备不应让使用者感到"我是一个需要被照顾的老人"。它应该：
- 像任何人都想拥有的美好物件
- 放在客厅不尴尬，来访客人不会问"这是什么医疗设备？"
- 品质感 > 功能感，美学 > 技术

### 5.3 陪伴感设计

- **存在感**：呼吸灯让设备"活着"，但不聒噪
- **记忆感**：设备记住老人的偏好和故事，对话有连续性
- **成长感**：随时间推移，互动越来越默契
- **仪式感**：早安问候、晚间道安，建立日常节奏

### 5.4 安全感设计

- **物理安全**：圆润无锐角，底座防滑，重量适中不易碰倒
- **心理安全**：一键呼叫家人/急救，但不渲染恐惧
- **隐私安全**：无摄像头，物理静音按钮，数据本地优先
- **使用安全**：大按钮、大字体、语音引导，无需学习

---

## 6. 家居融合策略

设备应像以下家居物件一样自然融入环境：
- 无印良品的香薰机（安静、有光、有存在感）
- 丹麦设计的木质音箱（材质温暖、工艺精良）
- 日式陶器花器（有机形态、手工感、安静）

**放置场景**：
- 客厅边桌（与茶杯、书籍并置）
- 卧室床头柜（替代传统闹钟/小夜灯）
- 书房书架（与植物、相框共存）
