3. **Priority 3 — Build merchandise by category.** Produce tote, notebook, and badge views in the manifest order so Critic can verify category coverage quickly.
4. **Priority 4 — Tote execution.** Use the tote reference assets as geometry/material starting points only; apply the official iDVX mark, restrained caption/mono labeling, and Campus Data Grid details without copying peer layouts.
5. **Priority 5 — Notebook execution.** Generate a cover and open-spread pair that feel academic, modular, and printable; keep text sparse, factual, and free of nonsense filler.
6. **Priority 6 — Badge execution.** Generate a readable small-scale badge family plus one macro craft shot; keep badge shapes simple and institutionally credible, not hype-fashion.
7. **Priority 7 — Collection and campus context.** Create one lineup image showing all three merchandise types together, then one Tongji-grounded campus application scene using the official campus photo as edit reference.
8. **Priority 8 — Gallery assembly.** Build `artifacts/00-gallery.html` as a single self-contained page with sections in this order: intro/system summary, Tote, Notebook, Badge, Collection, Campus, Research Provenance.
9. **Priority 9 — Final sanity pass.** Check that every PNG matches manifest filenames, uses only declared token names/colors, includes the required typography roles in prompt intent, and avoids all banned clichés and brand-lock conflicts.

Notes:
- Plan size is intentionally curated around the requested merchandise set: 8 PNGs + 1 gallery HTML (`min_items = 9`).
- Asset preservation is strict: public Tongji / IDVX identity assets are extended, never replaced.
- If higher-resolution official merch or campus assets emerge during design, they may replace weaker peer references but not change the approved system.
