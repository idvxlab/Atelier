# PyGame Tetris\n\n一个使用 **pygame** 编写的像素复古风俄罗斯方块小游戏。\n\n## 功能\n- 7 种经典方块\n- 左右移动、旋转、软降、硬降\n- 消行、分数、等级、速度提升\n- 下一个方块预览\n- 开始页、暂停、游戏结束、重新开始\n- 本地最高分存档\n\n## 运行方式\n```bash\npip install pygame\npython main.py\n```\n\n## 操作说明\n- `← / →`：左右移动\n- `↑` 或 `X`：顺时针旋转\n- `Z`：逆时针旋转\n- `↓`：软降\n- `空格`：硬降\n- `P`：暂停\n- `R`：重新开始\n- `Enter`：开始游戏 / 继续\n\n## 文件结构\n- `main.py`：入口\n- `game.py`：主循环和界面\n- `board.py`：棋盘与消行\n- `tetromino.py`：方块生成与旋转\n- `config.py`：全局配置\n- `storage.py`：最高分存档\n
